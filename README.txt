Public source: https://github.com/Artix6034/itransition_task6

Free Render database expires December 3, 2026. Recreate it or change the plan before then.

Runtime: Python 3.11+, PostgreSQL 14+.

Set DATABASE_URL to a PostgreSQL connection URI. Use a database created for
this application. init_db.py creates the fake schema and replaces the lookup
tables; it should be run by the database owner during deployment.

    pip install -r requirements.txt
    python init_db.py
    python app.py

Open http://127.0.0.1:5066

The page supports English/USA and German/Germany, arbitrary text seeds and
10-record batches. Generate restarts at batch 1. Next/Previous preserve the
seed and locale. The API accepts offset and count; see /docs.

All contact data is generated by PostgreSQL stored procedures. Python only
validates arguments, calls CALL/FETCH and renders the returned data.
Lookup CSVs are included, so Faker is not a runtime dependency.

Procedure documentation: docs/procedures.html, also served at /docs.
Benchmark: python benchmark.py --count 100000 --repeats 3
The measured local result is saved in benchmark.json. SQL generation and
materialization are timed; row transfer and page rendering are excluded.

Deployment on Render
- Create a PostgreSQL database or use an existing dedicated PostgreSQL database.
- Set DATABASE_URL in the web service. Do not commit the URI to Git.
- The included render.yaml defines a free Python service. It does not create
  a paid database. Select the database plan separately and review its terms.
- Build command: pip install -r requirements.txt && python init_db.py
- Start command: python app.py
- Set HOST=0.0.0.0. The host provides PORT.
- Check /health, /docs, both locales and repeatability from the deployed URL.
Reference: https://render.com/docs/deploy-flask

No Markov-chain text extension is included (it is optional in the task).
