← Contact generator

SQL procedure reference

The database generates every contact field. Python validates request arguments, calls the batch procedure and renders its rows. No Faker code or random-number generation runs in the application.

Installation

Use PostgreSQL 14 or later and Python 3.11 or later. Set DATABASE_URL, install requirements.txt, and run python init_db.py. This creates the fake schema, procedures and locale dictionaries. Initialization replaces the two lookup tables; run it during deployment, outside user requests.

BEGIN;
CALL fake.generate_users('en_US', '42', 0, 10, 'contacts');
FETCH ALL FROM contacts;
COMMIT;

The cursor is valid inside the transaction. Fetch before committing. A new call in the same transaction replaces that transaction's temporary generated table; close or consume the preceding cursor first.

Batch procedure

ArgumentTypeMeaning
p_localetextExisting locale code, initially en_US or de_DE.
p_seedtextAny seed string up to 128 characters. Case and leading zeros matter.
p_offsetbigintZero-based first record, from 0 to 10¹².
p_countintegerNumber of records, 1 to 1,000,000. The web page uses 10 and the public API caps requests at 1,000.
resultINOUT refcursorCaller-chosen cursor name, default fake_users.

Returned columns: position, full_name, address, latitude, longitude, height_cm, weight_kg, eye_color, phone, email. Position is zero-based. Heights and weights retain full floating-point precision in the API; the page rounds their display.

Helper procedures

All output parameters below are INOUT. Pass NULL or an initialized variable when calling a helper.

ProcedureInputsOutputs and algorithm
fake.uniformslocale text, seed text, position bigint, count integerresult double precision[]. For stream s, hash the JSON tuple [locale, seed, position, s] using MD5. Convert the first 52 bits to integer h. Return (h+0.5)/2⁵², strictly between zero and one. Deterministic pseudo-random data, not cryptographic randomness.
fake.normal_valueu1, u2, mean, deviation (double precision)result double precision. Box-Muller: mean + deviation × sqrt(-2 ln u1) × cos(2πu2). Requires 0 < u1,u2 < 1 and deviation ≥ 0.
fake.coordinatesu1, u2 (double precision)latitude and longitude (double precision, degrees). Latitude = asin(2u1−1) × 180/π; longitude = 360u2−180. This is uniform by sphere surface area because sin(latitude), not latitude, is uniform.
fake.format_texttemplate text, keys text[], vals text[]result text. Replaces each {key} by the corresponding value. The key and value arrays must have equal length.
fake.person_nameuniform array, first-name array, surname array, template array, title textfirst_name, last_name, full_name (text). Selects locale dictionary entries and a template with an optional middle name or title.
fake.address_textuniform array, streets[], cities[], postals[], templates[], country textresult text. Selects a city/postcode pair, street, building number (1–999), optional unit (1–99) and a locale address template.

Reproducibility and distributions

Web batch b, item i maps to position 10b+i. The generator does not use database global RNG state, time, connection identity or query order. Requesting batches out of order gives identical records. Changing the batch size also preserves every absolute position.

Independent streams select gender, names, address components, phone format, coordinates, normal attributes and eye color. Height is normal with standard deviation 7 cm and means 178/165 cm. Weight is normal with standard deviation 12 kg and means 80/65 kg. Gender groups have equal probability. The combined population is a mixture of these two normal distributions. Values are not clipped. Very rare implausible tails are possible.

Coordinates are sampled over the whole sphere and deliberately do not identify the generated address. Addresses, city/postcode combinations and telephone numbers are fictional; this library does not validate postal deliverability. Email uses the reserved test domain.

Dictionaries and adding a locale

The shared tables are fake.locales (templates), fake.words(locale,kind,ordinal,value) and fake.places(locale,ordinal,city,postal_code). A new locale needs rows in these tables, not new tables or Python branches. Word kinds are first_male, first_female, surname and street. Keep ordinals stable: dictionary changes can change previously generated output even for the same seed.

Lookup words come from the MIT-licensed Faker project, version 40.44.0, en_US and de_DE providers. Streets and fictional city/postcode pairs were prepared once, using a fixed seed, and saved as CSV. These CSV files are the runtime data source. See data/NOTICE.txt for provenance and the included license.

Benchmark

python benchmark.py --count 100000 --repeats 3

The benchmark times SQL generation and temporary-table materialization. It excludes network transfer and HTML rendering. See benchmark.json for the measured local result. Throughput depends on the database CPU, configuration and number of requested rows.

HTTP API

GET /api/users?locale=de_DE&seed=42&offset=10&count=10

The API returns a JSON array. /health checks database connectivity. /docs serves this reference. The optional Markov-chain text extension is not implemented.
